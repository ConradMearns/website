Vibechecks

A vibecheck is a quick, mostly vibe-coded test of an idea or a model: I describe what I want, let an LLM build it, and see whether the idea holds up. Built in an evening and judged by feel, not rigor. Some work, some semi-fail, and both are the point.

  • Neutral Loss Spectra — an interactive tutorial for GC-MS & LC-MS (page only)
  • Marginalia — embedding-based qualitative coder, then a matched-filter rewrite (page only)
  • Origins — a Xanadu-style transclusion view (page only)
  • Self-Editing Page — selection + LLM jobs (page only)
  • Island Forge — a semi-failed dynamic system editor (page only)
  • ECS × LISP — a tiny world you drive with s-expressions, with agents that sense, think and act (page only)
  • ChronicleDB — a Raft-consensus distributed event log demo, in React and in vanilla JS (page only)
  • Meal Planner — calendar, servings, grocery list (page only)
  • Whiteboard — an infinite-canvas flow diagram planning a DIZZY feature (page only)
  • Terminal — an 80s CRT boot screen (page only)
  • Barcode Scanner — a vanilla-JS PWA that scans barcodes with the phone camera (page only)
  • VibeCheck — the original: embed team thoughts, find themes, generate survey questions (2025 proof of concept)
