Vibechecks

A vibecheck is a quick, mostly vibe-coded test of an idea or a model: I describe what I want, let an LLM build it, and see whether the idea holds up. Built in an evening and judged by feel, not rigor. Some work, some semi-fail, and both are the point.

  • Neutral Loss Spectra — an interactive tutorial for GC-MS & LC-MS
  • Marginalia v1 — embedding-based qualitative coder
  • Marginalia v2 — matched-filter qualitative coding
  • Origins — a Xanadu-style transclusion view
  • Self-Editing Page — selection + LLM jobs
  • Island Forge — a semi-failed dynamic system editor
  • ECS × LISP — a tiny world you drive with s-expressions, with agents that sense, think and act
  • ChronicleDB — a Raft-consensus distributed event log demo (vanilla JS build)
  • Meal Planner — calendar, servings, grocery list
  • Whiteboard — an infinite-canvas flow diagram planning a DIZZY feature
  • Terminal — an 80s CRT boot screen
  • Barcode Scanner — a vanilla-JS PWA that scans barcodes with the phone camera
  • VibeCheck — the original: embed team thoughts, find themes, generate survey questions (2025 proof of concept)
