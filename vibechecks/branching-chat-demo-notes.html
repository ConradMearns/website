Branching Chat Demo

A chat whose messages are stored as a tree: edit an earlier message or retry a reply and both versions are kept. Switch branches in the thread, or flip to a commit-graph style tree with one lane per branch. No model is connected; replies are canned so you can watch the tree grow.
