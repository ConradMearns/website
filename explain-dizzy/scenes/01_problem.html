In 1980, Lehman described three kinds of program.
S-type. Specified once, then finished.
P-type. Fitted to a problem;
it changes when the problem does.
E-type. Part of the world it serves; each changes the other.
Every change costs more than the last.
So how do you assure something
that never stops changing?
