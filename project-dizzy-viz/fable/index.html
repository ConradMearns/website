hover a node — pulses show messages flowing between components
Click a processor button (or let AUTO run) and watch one user intent become a chain: a command is queued, its procedure drives the arm and emits events — immutable facts. Policies react to facts by dispatching new commands (the dashed feedback arcs), while projections fold the same facts into models. Note the read models lag the scene slightly: they know only what the events have told them. Processing fails ~20% of the time — failures are facts too, and the retry_processing policy handles them.
